  - 관리자 페이지: http://127.0.0.1:8000/admin/ (admin / admin1234!)

================================================================
  1. JWT REST API 엔드포인트 (멀티에이전트/API용)
================================================================

본 시스템은 외부 에이전트 연동을 위해 JWT(JSON Web Token) 인증을 지원합니다.
모든 API 요청 및 응답은 JSON 형식을 사용합니다.

[A] 회원가입 (POST /api/auth/signup/)
  - 요청 바디:
    {
      "username": "아이디",
      "name": "이름",
      "gender": "M", (M/F)
      "age": 25,
      "password": "비밀번호(8자이상)",
      "password2": "비밀번호확인"
    }
  - 성공 응답 (201): 유저 정보와 함께 토큰 발급

[B] 로그인 & 토큰 발급 (POST /api/auth/login/)
  - 요청 바디:
    {
      "username": "아이디",
      "password": "비밀번호"
    }
  - 성공 응답 (200):
    {
      "access": "액세스_토큰_문자열",
      "refresh": "리프레시_토큰_문자열",
      "user": { ...유저정보... }
    }

[C] 내 정보 조회 (GET /api/auth/me/)
  - 헤더 필수: Authorization: Bearer <액세스_토큰>
  - 성공 응답 (200): 현재 토큰에 해당하는 유저 정보 반환

[D] 로그아웃 (POST /api/auth/logout/)
  - 헤더 필수: Authorization: Bearer <액세스_토큰>
  - 요청 바디: { "refresh": "리프레시_토큰_문자열" }
  - 효과: 리프레시 토큰이 블랙리스트에 등록되어 재사용 불가해짐

[E] 토큰 갱신 (POST /api/auth/token/refresh/)
  - 액세스 토큰 만료 시 사용
  - 요청 바디: { "refresh": "리프레시_토큰_문자열" }
  - 성공 응답 (200): 새로운 액세스 토큰 발급

================================================================
  2. 데이터베이스 구성 (SQLite3)
================================================================

테이블명 : accounts_user

  컬럼명        | 설명
  --------------|---------------------------------------------
  id            | 고유 PK
  username      | 로그인 ID (특수문자 제외)
  name          | 사용자 실제 성함
  gender        | 성별 (M=남성, F=여성)
  age           | 나이 (정수)
  password      | PBKDF2 해시 암호화된 비밀번호
  is_login      | 로그인 상태 플래그 (1=로그인중, 0=로그아웃)
  date_joined   | 가입 일시

================================================================
  3. 보안 및 특이사항
================================================================

1. 비밀번호 암호화:
   - 클라이언트에서 평문으로 보내도 서버가 DB 저장 시점에 자동으로 
     강력한 해시 알고리즘(PBKDF2+SHA256)으로 암호화합니다.
   - DB를 직접 열어봐도 비밀번호 원문을 알 수 없습니다.

2. 로그인 상태 동기화:
   - API를 통한 로그인/로그아웃 시에도 DB의 `is_login` 필드가 
     실시간으로 업데이트됩니다 (어드민에서 확인 가능).

3. 토큰 유효기간:
   - Access Token: 1시간
   - Refresh Token: 7일
