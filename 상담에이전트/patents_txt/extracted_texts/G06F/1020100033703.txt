을 형성한다. 데이터 송수신부(510)는 디스플레이 장치(10)로부터 물리적 통신 채널을 통해 패킷화된 제어 신호
를 수신하여 데이터 처리부(520)로 전달한다.
데이터 처리부(520)는 패킷화된 제어 신호를 분석하여 실행 중인 애플리케이션에 대한 제어 신호를 판별한다.
[0038]
데이터 처리부(520)는 판별된 제어 신호를 동작 제어부(530)로 전달하여 동작 제어부(530)가 애플리케이션의 동
작을 제어할 수 있도록 한다.
동작 제어부(530)는 데이터 처리부(520)에 의해 판별된 제어 신호에 기반하여 실행 중인 애플리케이션의 동작을
[0039]
제어한다.  동작 제어부(530)는 애플리케이션의 동작 제어에 의해 애플리케이션의 동작 화면이 변경됨을 디스플
레이 처리부(540)에 알린다.
디스플레이 처리부(540)는 동작 제어부(530)의 동작 제어에 의해 변경된 애플리케이션의 동작 화면을 디스플레
[0040]
이 인터페이스(600)로 전달한다.  디스플레이 인터페이스(600)는 디스플레이 처리부(540)로부터 수신한 애플리
케이션의 동작 화면을 비디오 신호로 가공하여 디스플레이 장치(10)로 출력한다.
[도 3]은 본 발명에 따른 디스플레이 장치의 입력 장치를 이용한 호스트 제어 방법의 동작 흐름도이다.
[0041]
호스트 제어 시스템을 구성하는 호스트 장치와 디스플레이 장치가 서로 데이터 통신하여 디스플레이 장치에 의
[0042]
해 호스트 장치의 동작이 제어됨을 시계열적 흐름에 따라 설명하면 다음과 같다.
호스트 장치와 디스플레이 장치는 비디오 인터페이스와 통신 인터페이스에 의해 서로 물리적으로 연결되어 비디
[0043]
오 신호의 송수신과 데이터의 송수신을 위한 통신 채널을 형성한다.
호스트 장치는 디스플레이 장치와 데이터 통신 채널을 형성하여 디스플레이 장치로부터 디스플레이 장치의 사양
[0044]
정보를 수신한다(S101).  디스플레이 장치의 사양 정보로는 화면 해상도, 입력장치의 구성, 디스플레이 인터페
이스에 대한 정보 등이 포함된다.
호스트 장치는 디스플레이 장치의 사양 정보 중 디스플레이 인터페이스에 대한 정보를 참조하여 실행 중인 애플
[0045]
리케이션의 동작 화면을 비디오 신호로 가공한다(S102).
호스트 장치는 디스플레이 인터페이스를 통해 디스플레이 장치로 비디오 신호를 전송한다(S103). 디스플레이 인
[0046]
터페이스로는 DVI(digital visual interface), RGB, MIPI(Mobile Industry Processor Interface), HDMI(High
Definition Multimedia Interface) 등의 비디오 신호 프로토콜이 사용된다.
디스플레이 장치는 호스트 장치로부터 비디오 신호를 수신하고 비디오 디코딩 과정을 실행하여 비디오 버퍼에
[0047]
비디오 데이터를 기록해서 화면에 호스트 장치에서 실행 중인 애플리케이션의 동작 화면을 표시한다(S104).
디스플레이 장치는 터치 입력장치, 키 입력장치, 트랙볼 입력장치 등의 입력장치로부터 사용자 조작에 따른 터
[0048]
치 신호, 키눌림 신호, 트랙볼 회전 신호 등의 조작 신호를 입력받는다(S105).
디스플레이 장치는 입력장치의 조작 신호를 가공하여 터치 지점, 눌린 키, 트랙볼 회전 정도 등의 조작 정보를
[0049]
획득한다.
디스플레이 장치는 획득된 조작 정보 중 디스플레이 장치에 대한 제어 신호인지 호스트 장치에 대한 제어 신호
[0050]
인지를 판별하여 호스트 장치에 대한 제어 신호를 호스트 장치로 전송할 절차를 실행한다(S106).
디스플레이 장치는 호스트 장치에 대한 제어 신호를 호스트 장치와의 통신 프로토콜에 따라 패킷화한다.  그리
[0051]
고 디스플레이 장치는 패킷회된 제어 신호를 물리적 통신 채널을 통해 호스트 장치로 전송한다(S107).
호스트 장치는 디스플레이 장치로부터 제어 신호를 수신하고 수신된 제어 신호에 따라 실행 중인 애플리케이션
[0052]
의 동작을 제어한다(S108).  이러한 호스트 장치의 동작을 세분화하여 설명하면 다음과 같다.
호스트 장치는 디스플레이 장치로부터 물리적 통신 채널을 통해 패킷화된 제어 신호를 수신한다. 호스트 장치는
[0053]
디스플레이 장치와의 데이터 통신 프로토콜로 UART(Universal  Asynchronous  Receiver/Transmitter),
I2C(Inter-Integrated Circuit), USB(Universal Serial Bus) 등을 이용한다.
호스트 장치는 패킷화된 제어 신호를 분석하여 실행 중인 애플리케이션에 대한 제어 신호를 판별한다.  호스트
[0054]
장치는 판별된 제어 신호에 기반하여 애플리케이션의 동작을 제어한다.
