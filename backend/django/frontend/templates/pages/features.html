Why PYPI

PYPI의
원칙과 특징

전문가급 품질, 신속한 자동화, 종합 파이프라인 — 세 가지 원칙으로 특허 출원을 혁신합니다.

01

전문가급 품질

특허청 규정에 맞춘 독립항·종속항 구성과 품질 점수 자동 검수로 전문 변리사 수준의 출력을 제공합니다.

  • 특허청 작성 규정 기반 청구항 자동 구성
  • 도면 품질 점수(0~100) 자동 산정 및 S/A/B/C 등급 부여
  • 명세서 각 섹션의 특허 문체 자동 적용
  • Composer 에이전트의 최종 용어·참조부호 통일 검수
02

신속한 자동화

아이디어 입력 한 번으로 7개 에이전트가 협력하여 수일이 걸리던 특허 작성을 자동으로 완성합니다.

  • LangGraph 기반 에이전트 파이프라인 자동 실행
  • 요약→청구항→명세서→통합 순서 자동 처리
  • GPT-4o 기반 고품질 텍스트 생성
  • OpenAI Streaming API로 실시간 결과 확인
03

종합 파이프라인

상담부터 도면·명세서·최종 통합까지 단일 파이프라인에서 완결되어 제출 가능한 문서를 출력합니다.

  • 7개 에이전트 공유 State(PatentAgentState) 기반 통합
  • 최종 DOCX 파일 자동 생성
  • 도면 SVG + 명세서를 하나의 패키지로 병합
  • 한국어·영어·일본어·중국어 4개 언어 지원
