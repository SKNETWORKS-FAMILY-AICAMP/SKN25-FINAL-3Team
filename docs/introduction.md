# 프로젝트 소개

## 1) 프로젝트 주제
개인 발명가 및 변리사를 위한 **특허 명세서 자동 작성 서비스**

---

## 2) 문제 정의

특허는 기술과 법률이 교차하는 영역이며, 현재 다음 두 가지 장벽이 존재합니다.

### (1) 개인 발명가의 법적 장벽
개인 발명가와 중소기업은 특허법 특유의 복잡한 서식과 법률 용어에 익숙하지 않은 경우가 많습니다.  
그 결과, 발명에 대한 법적 보호를 포기하거나, 등록을 받더라도 권리 범위가 협소해지는 등 **부실 특허 위험**에 노출됩니다.

### (2) 변리사의 기술적 장벽
변리사는 급변하는 딥테크 분야의 신규 기술을 다룰 때, 기술의 핵심을 파악하고 이를 명세서에 반영하는 데 많은 시간과 에너지를 소모합니다.

---

## 3) 서비스 개요

본 서비스는 발명가(또는 변리사)가 일상 언어로 기술을 설명하면, 이를 특허법적 요건(신규성, 진보성, 기재불비 방지)에 부합하는 **정식 명세서 형태로 변환**하는 AI 기반 특허 엔지니어링 솔루션입니다.

### 기대 효과
- 개인 발명가의 특허 진입 장벽 완화
- 직접 출원 시 권리 보호 수준 강화
- 변리사 상담 시 참고 가능한 초안 명세서 제공
- 변리사의 문서 작성 효율 향상

---

## 4) 시스템 구성

멀티 에이전트 구조를 활용합니다.

- 상담 Agent
- 청구항 작성 Agent
- 청구항 검토 Agent(심사관 Agent)
- 도면 작성 Agent
- 발명의 설명 작성 Agent

---

## 5) 에이전트별 역할

### 5.1 상담 Agent
- **목표**: 발명가로부터 명세서 작성의 기초가 되는 핵심 요소를 추출
- **입력**: 발명가의 자연어 설명
- **출력**:
  - 발명의 전체 흐름
  - 기존 기술의 문제점 및 차별점
  - 발명의 효과
  - 사용자 ID, 세션 번호, 전체 대화 이력(별도 저장)

### 5.2 청구항 작성 Agent
- **목표**: 상담 Agent가 추출한 핵심 내용을 바탕으로 청구항 작성
- **입력**: 발명의 핵심 내용
- **출력**: 복수의 청구항  
  (방법/시스템(장치)/기록매체 청구항, 독립항/종속항을 폭넓게 생성 지향)

> OpenAI API 기반 프롬프트 엔지니어링을 통해, 발명의 핵심을 반영하면서 권리 범위를 최대화하는 청구항 생성을 목표로 합니다.

### 5.3 청구항 검토 Agent (= 심사관 Agent)
- **목표**: 청구항의 법적 적합성과 심사기준 충족 여부 검토
- **입력**: 청구항 작성 Agent의 결과물
- **출력**: 등록 가능/불가 의견 및 근거

#### 학습 계획
- 법률 도메인 특화 지식 강화를 위해 파인튜닝 적용 예정
- 데이터셋: KIPRIS 공개 문서(의견제출통지서, 거절결정통지서, 등록결정서 등)
- 목표: 실제 심사관 수준의 등록 가능성 판단 보조

### 5.4 도면 작성 Agent
- **목표**: 청구항 기반 도면 생성
- **입력**: 청구항 작성 Agent의 청구항
- **출력**: 복수 도면(예: 흐름도, 시스템 구성도)

> 도면 생성에는 `mermaid.js`를 활용할 예정입니다.

### 5.5 발명의 설명 작성 Agent
- **목표**: 핵심 내용과 도면을 바탕으로 발명의 상세한 설명(실시예) 작성
- **입력**:
  - 상담 Agent가 추출한 발명의 핵심 내용
  - 도면 작성 Agent가 생성한 도면
- **출력**:
  - 배경기술
  - 발명의 내용(해결하려는 과제, 해결수단, 효과)
  - 도면의 간단한 설명
  - 발명을 실시하기 위한 구체적 내용

---

## 6) 향후 논의 사항

각 Agent 간 데이터 전달 방식, 검토 루프, 재생성 조건 등 **에이전트 간 협업 구조**는 추후 상세 설계가 필요합니다.
